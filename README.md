# Growth with AI —— 由「知道」走到「做到」

> **公開版 · 2026-08**

Growth with AI 由一件真工作開始：先做出可驗收成果，慢慢建立 context、可交接做法與可靠系統，最後用真實 workflow 判斷有沒有創造價值。

呢份唔係工具清單、prompt 合集，更唔係 marketing 教材。它是一個 **AI 實戰攻略 library**：無論你做營運、教學、研究、產品、設計或其他知識工作，都可以由現在卡住的工作問題開始，做一個安全、可驗收的下一步，逐步建立可交接、可改善和可創造價值的 AI 工作方法。

## 呢份 library 的四個規矩

1. **每篇只解一個真工作問題。** 它要講清機制、第一步和何時不適用，而不是堆工具名。
2. **例子要安全。** 只用公開、generic 或 synthetic 材料；客戶、合約、CRM、付款、credentials 和不可逆外部操作不會出現。
3. **來源和教學分開。** 讀者頁先幫你學識做事；公開引用集中在 [SOURCES.md](SOURCES.md)，不把私有工作筆記搬出來。
4. **職能只作例子，不作主線。** marketing、內容、課程、營運或產品的例子，只用來說明同一條通用 AI 工作能力怎樣落地；五個 Stage 的主線始終是實戰能力。

## 呢份嘢係點嚟嘅

每篇攻略由 Jimmy 的實踐、教學、比較和反思整理而成，只保留可以教學、重用和公開討論的做法。原始來源、私有 Source note、客戶資料和 Vault 路徑均不在這裡。

## 不會在這裡出現的內容

- 工具排行榜和「神 prompt」清單；
- 收入承諾或未驗證的成功數字；
- 客戶、學員、CRM、合約、付款或未公開資料。
