# 收藏一堆爆款仍然唔識選題？你存的是單條，選題需要的是比較與判斷

刷到一條數據很好的內容時，收藏是一個很自然的動作。幾個月後要決定下一篇寫甚麼，打開收藏夾卻只有一堆零散連結：你記得當時覺得它好，但不知道它為何好、可不可以借、又應該放到自己的哪一個讀者問題上。最後仍然只能憑感覺選題。

問題不是你看得不夠多，而是收藏的單位和選題需要的單位不同。收藏保存的是「某一條看起來不錯」；選題需要的是條與條之間的比較：它相對平常是否異常、它解開了哪種讀者張力、哪些機制可遷移、哪些成果只屬對方的背景。

Jimmy 的判斷是：公開內容訊號可以幫你提出假設，不能替你複製別人的結果。先把單條訊號變成一張選題卡，再用一個小型內容測試收回自己的 evidence；這樣外部觀察才會變成可回看的工作判斷，而不是另一個更漂亮的收藏夾。

| 選題判斷位置 | 要問甚麼 | 留下甚麼 |
|---|---|---|
| 公開訊號 | 這條相對自己的常態有甚麼不同？ | 值不值得深讀的候選 |
| 讀者張力 | 它戳中了甚麼工作摩擦或誤會？ | 可描述的問題 |
| 可借／不可借 | 機制能遷移嗎？背景依賴甚麼？ | 安全改寫邊界 |
| 小假設 | 我想只測哪一個變數？ | 一條內容實驗 |
| 回看 | 自己的讀者有何反應？ | 保留／修正／退休判斷 |

## 收藏夾點解幫不到你選題？一條內容只能保存感覺，不能提供比較基準

按收藏時，你通常只知道「這一條好像很勁」。但真正要選題時，你需要回答更多：它在作者自己的內容裡是不是異常？它是不是剛好碰到時事？它用了甚麼可以解釋的結構？它服務的受眾，和你想幫的人是否真的相同？單條內容無法回答這些問題。

因此收藏愈多，未必愈有方向。你收集的是結果，選題卻需要解釋；沒有比較基準，任何高數字都很容易被誤當成「這個題目值得我抄」。外部內容最多是輸入，不應直接變成你的內容決定。

Jimmy 的結論是：收藏不是沒有價值；它只是一個候選入口。選題要開始有用，必須把單條放回一組可以比較的公開訊號裡。

先將收藏分成三種：

| 類型 | 它可以提供甚麼 | 暫時不能提供甚麼 |
|---|---|---|
| 單條高反應內容 | 一個值得問「為何」的候選 | 一個已證明可複製的方法 |
| 同類題目多次出現 | 一個可能的讀者張力 | 對你自己的結果保證 |
| 公開評論／問題 | 讀者語言與困惑線索 | 完整市場調查結論 |

這樣看時，你會少問「這條可不可以抄」，多問「我需要再比較甚麼，才值得把它變成一個選題假設」。

## 同樣一萬讚，點解可能是兩件完全不同的事？先找相對異常，不是只看大數字

一條內容有一萬個讚，聽起來很大；但若作者平常每條都有幾萬讚，這可能是日常。相反，一個平常只有幾百讚的帳號突然出現一萬讚，才值得研究它是否碰到不同受眾、不同題目或不同形式。數字本身沒有意思，除非你知道它相對甚麼。

不過「異常」也不是證明因果。它可能來自時事、合作、付費推廣、既有觀眾或你看不到的外部條件。它的價值只是幫你決定哪幾條值得花時間深讀，而不是叫你立刻照搬開場句或內容形式。

Jimmy 的結論是：你要找的不是高數字，而是值得問「相對甚麼、為甚麼不同」的異常訊號。

快篩時可先看：

| 問題 | 為何要問 |
|---|---|
| 它相對作者近期香港內容的常態如何？ | 分清異常與日常 |
| 帳號發文節奏與受眾有沒有改變？ | 避免用舊基準解釋新情況 |
| 是否剛好借到時事、人物或平台分發？ | 標出可能不可借背景 |
| 同類題目有沒有其他反例？ | 不把一條結果當規律 |

若基準不可靠，直接把「不確定」寫在卡上。這比用一個看似精準的數字作錯判斷更有用。

## 快篩和深讀點樣分工？先讓「我還不知道」有地方放

如果每一條公開內容都深入拆解，你很快會被工作量淹沒；若只靠短暫感覺收藏，又永遠不能形成判斷。兩層流程能解決這個矛盾：快篩處理所有候選，深讀只留給異常、與你工作相關、而且你真的想理解的少量內容。

快篩的目的不是下結論，而是標出有哪些資料尚欠。深讀才去看完整內容、公開討論、相近反例與內容結構，並且檢查它能否誠實地被轉成你的受眾問題。這種分法能避免你為了「分析完」而硬把所有觀察升級成洞見。

Jimmy 的結論是：分兩層不是為了慳時間，而是讓未知能保留為未知，直到有足夠證據才變成選題判斷。

| 層 | 每條要留下 | 不應做甚麼 |
|---|---|---|
| 快篩 | 異常與否、初步張力、欠甚麼資料 | 將未看完整內容寫成結論 |
| 深讀 | 結構、可借機制、不可借背景、一個小假設 | 把對方結果包裝成自己的 proof |

每周只挑少量深讀候選。若一條內容沒有足夠公開材料或不適合你的工作主線，可以保留為參考，而不必強迫自己從中學出一條規則。

## 一張選題卡應該留甚麼？把別人的結果拆成可借機制與不可借背景

很多內容分析只記 hook、文案結構和數據。這些固然有用，但最容易令人照抄表面：同一句開場、同一個版型、同一種節奏，放到自己帳號卻完全走樣。原因是你沒有分辨那條內容成功的是哪個可遷移機制，還是作者本身的知名度、時事位置或特殊背景。

選題卡的價值在於強迫這個分界。它不會讓你預測內容必定有效，但會令你在起草前已知道你打算借的是「怎樣提出讀者摩擦」還是「某個人專屬故事」。後者通常不應被複製，只能作為提醒你找自己的例子。

Jimmy 的結論是：外部內容真正能借的，不是對方的成果，而是你能用自己證據重新驗證的工作機制。

| 選題卡格 | 要寫甚麼 |
|---|---|
| 來源與基準 | 公開 URL、日期、可比較範圍及可靠性 |
| 讀者張力 | 它戳中哪個不安、誤會或工作摩擦 |
| 結構 | 開場如何建立問題、例子如何支撐判斷 |
| 可借機制 | 例如先拆常見誤會，再用小工作示範 |
| 不可借背景 | 作者名氣、時事、私人經驗、未能核對的成果 |
| 小假設 | 自己下次只想測哪一個變數 |

最後兩格最重要。沒有「不可借」和「小假設」，這張卡只會變成精緻收藏，而不會改變下一次內容工作。

## 外部訊號點樣變成你自己的選題？用讀者工作摩擦重新寫，而不是換幾個字

看到一條好內容後，最容易的做法是保留它的句子，再換成自己的詞。這種改寫通常只有表面相似：原作者的受眾、身份和時事條件不存在時，內容便失去理由。讀者也會感覺到你只是在引用一個不屬於自己的結論。

較好的轉換方式，是回到你自己的讀者正在做甚麼、最容易誤會甚麼、你有甚麼公開或 synthetic 例子可以負責。外部訊號只幫你看見一個可能張力；真正的文章必須由你的工作判斷、教學方法和安全邊界重新站起來。

Jimmy 的結論是：你的版本不應是把別人內容翻譯成自己的語氣，而是用自己的讀者問題重新驗證一個可借機制。

把卡上的假設改寫成這四句：

1. 我的讀者目前在哪一件真工作上卡住？
2. 他最可能沿用哪個不夠的舊看法？
3. Jimmy 的工作判斷會怎樣重新說這件事？
4. 我能用哪個公開／synthetic 例子讓他看見第一小步？

若你答不到其中任何一句，這個訊號還未夠資格變成公開內容。先保留卡片或找更多自己的 evidence，而不是急著出稿。

## 第一週怎樣跑得動？十個候選、三張深讀卡、一個小內容假設已經夠

剛開始做訊號比較時，很容易想建立大量競品帳號清單、抓取所有數據、每天分析十幾篇。這種範圍很快令工作回到收藏與研究，反而沒有一條內容被真正測試。第一週的目標不是找到爆款，而是完成一次從公開訊號到自己判斷再到小測試的完整 loop。

範圍愈小，你愈容易知道這套方法有沒有幫到自己選題。選十個公開候選、深讀三條、只押一個小假設；完成後看自己的讀者反應和內容品質，再決定要保留、調整或退休哪條判斷。這比追求一堆看似完整的數據更誠實。

Jimmy 的結論是：外部訊號的第一輪成功，不是找到爆款，而是你能講出為何選這個題目、借哪個機制、又準備怎樣驗證。

```text
10 個公開候選
→ 快篩：異常／張力／未知
→ 深讀 3 條，寫選題卡
→ 選 1 個小假設
→ 做 1 條自己的內容
→ 回看：保留／修正／退休判斷
```

每次只改一個變數，例如開場先講哪種工作摩擦，或例子是否放在前段。不要一次換題目、形式、語氣、渠道和 CTA；否則你無法知道自己真正學到甚麼。

## 用 AI 工作教學主題跑一次：別人的內容怎樣只變成你的起點，而非複製品

以下是 synthetic 例子。你看到一條公開內容反應很高，主題是「AI agent」。快篩後你發現它可能受惠於熱門名詞與作者既有受眾，因此不能把高反應當作你也應出一條 agent 新聞。深讀時你保留的不是它的句子，而是它先指出讀者常見誤會、再用一個具體工作例子拆解的結構。

你的選題卡再回到自己的讀者：已會用 ChatGPT，但仍以為 AI agent 等於另一個聊天工具。你用公開或 synthetic briefing 例子說明「先把工作交代清楚，才值得談 agent」，而不是聲稱自己複製了別人的成效。

| 卡片位置 | 本輪內容 |
|---|---|
| 外部張力 | 讀者把 agent 當神奇工具，忽略工作條件 |
| 可借機制 | 先拆錯誤 mental model，再跑小例子 |
| 不可借背景 | 對方帳號影響力、時事熱度、私人案例 |
| Jimmy 版本 | 「Agent 不是多一個 chat；先把一件工作交代得可驗收」 |
| 小假設 | 先寫工作摩擦的開場，是否令新手更易理解下一步 |

Jimmy 的結論是：這一輪真正新增的是一條屬於你自己的內容判斷；外部內容只是幫你發現值得問的問題。

發出後只回看可觀察的反應和質性問題，不要把一次結果誇大成內容策略已被證明。下次根據 evidence 調整選題卡，才會真正建立自己的訊號庫。

## 今日怎樣開始？先寫三張選題卡，而不是再存三十條連結

今天不用建立完整 competitor system。選三條你已收藏、而且公開可回看的內容，先做快篩：基準可靠嗎？它可能的讀者張力是甚麼？有甚麼你尚不知道？只讓一條真正值得的內容進入深讀，寫出可借／不可借和一個小假設。

下一步不是立即模仿，而是把假設改寫成自己的讀者工作摩擦，配一個能公開或 synthetic 說明的例子。若最後仍沒有足夠自己的 evidence，寧願不出；一張誠實寫著「暫時不可借」的卡，比一篇走樣的複製品更有價值。

Jimmy 的結論是：你存的是單條，選題需要的是比較；真正屬於你的內容，由你如何把比較變成可驗證判斷開始。

今天請做：

1. 選三條公開收藏，快篩異常、張力和未知；
2. 深讀一條，完成來源、可借、不可借、小假設四格；
3. 將假設翻成自己讀者的一件工作摩擦；
4. 用一個公開／synthetic 例子起一個可 review draft；
5. 發出或內部 review 後，將自己的 evidence 回填選題卡。

想把外部 source 先消化成自己的工作判斷，可讀 [一篇 source 點樣先變成你自己的工作判斷？](<../../02-AI Super User（AI熟練使用者）/chapters/練習-turn-a-source-into-your-own-decision.md>)。當一條內容流程已開始重複，才考慮把它做成有回饋的 AI Builder workflow，閱讀 [循環工程是回饋系統設計](<../../04-AI Builder（AI建立者）/chapters/4-3-loop-engineering.md>)。
