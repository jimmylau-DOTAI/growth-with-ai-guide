# AI 做影片和設計，點解出得快仍然唔好睇？創作工作要有可講清的 review grammar

AI 可以幫你生圖、剪短片、排版和寫 script。它讓素材和版本出得很快，也很容易讓人以為作品已經完成：畫面很滿、節奏很快、文字很多，但觀眾記不起重點，不知道下一步，或覺得每一張圖都像同一個模板。

問題不是生成工具不夠多，而是創作工作從來不只是一條 prompt。當「好看」只存在某個人直覺裡，AI 只能不停試；同事也只能猜。要把創作放進可重複工作，必須先把訊息、受眾、節奏、畫面層級和不能越過的邊界說出來。

Jimmy 的判斷是：AI 可以加快素材、版本和執行；人要把品味變成可 review 的 grammar。grammar 不是固定風格模板，而是一套令團隊能講清「這一版為何更接近目的」的工作語言。

| 創作位置 | 先問的問題 | 留下甚麼 |
|---|---|---|
| 訊息與受眾 | 這條內容要讓誰理解／感到甚麼？ | 一句創作意圖 |
| 故事與節奏 | 哪一秒、哪一段必須成立？ | storyboard／節奏線 |
| 畫面 grammar | 先看到甚麼，哪些只是輔助？ | visual brief |
| 版本與 review | 每一版在測甚麼？ | 有理由的比較 |
| Release 邊界 | 哪些事實、品牌、權限不能猜？ | 人手收貨條件 |

## AI 生到很多畫面，點解仍然像未完成？因為沒有一個創作意圖可以收貨

「做得高級啲」「有創意啲」「想吸睛」看似是方向，實際上不足以讓任何人 review。一個人看到畫面後覺得不對，可能是訊息不清、受眾不對、節奏太急、品牌不一致，或只是素材與目的無關。若不把這些分開，AI 只會收到更多形容詞，然後交回更多難以比較的版本。

創作意圖不是長篇靈感說明，而是讓團隊在開始前同意「這條作品最重要要做成甚麼」。有了意圖，你才知道該不該刪一個效果、停一段文字、或保留一個看似簡單的畫面。

Jimmy 的結論是：創作 output 不是畫面出現就完成，而是有人能指出它有沒有服務原本的訊息與受眾。

每次開始前先寫四句：

1. **對象：** 誰會看，對這件事已有甚麼理解？
2. **訊息：** 看完最應帶走哪一個判斷？
3. **感受／行動：** 希望他停下、比較、相信還是採取下一步？
4. **不可犧牲：** 哪些事實、品牌元素或安全邊界不可以為了效果而改？

這四句就是最小創作 brief。它讓你把「我覺得唔啱」轉成能讓人修正的理由。

## 短片或 carousel 的節奏點樣先唔會只有資訊？先決定觀眾在哪裡停、在哪裡明白

AI 特別容易把每一秒都塞滿：每句都有文字、每頁都有 icon、每個轉場都在動。這種做法看起來很努力，但觀眾沒有空間抓住主線。當一條內容沒有節奏，更多素材通常只會令重點更難被看見。

節奏不是只能靠天份感覺。你可以把一段內容拆成「為何要停、要理解甚麼、用甚麼例子證明、最後到哪裡」四個位置。這讓生成和剪輯工作有一條可 review 的線，而不是在眾多版本裡碰運氣。

Jimmy 的結論是：節奏的工作不是令內容一直很刺激，而是讓每個重要判斷有足夠位置被看見和記住。

| 節奏位置 | 要問甚麼 | 常見錯誤 |
|---|---|---|
| 開場 | 觀眾為何要停？ | 只放誇張句，沒有真問題 |
| 展開 | 要拆哪個誤會？ | 一開始便丟所有解法 |
| 例子 | 怎樣讓人看見這不是空話？ | 用太多素材，沒有因果 |
| 收尾 | 看完應帶走或做甚麼？ | 只叫人 like／follow，沒有下一步 |

畫 storyboard 時，先填這四格，再叫 AI 產出版本。當某一段變得太長，你就知道該刪的是哪一種資訊，而不是憑感覺重做整條片。

## 視覺 grammar 是甚麼？把「好看」拆成可比較的層級、節奏和限制

視覺工作常被誤解成「有一張 reference 圖，再叫 AI 模仿」。reference 可以幫你討論方向，但如果沒有講清楚它好在哪裡，AI 和團隊只會複製表面：同樣顏色、同樣構圖、同樣字體感，卻不知道訊息層級、留白和閱讀順序如何支持內容。

visual grammar 是把這些隱性的選擇變成可以對照的規則。它不是要每條作品長得一樣，而是讓每次選擇都有一個可說明的原因：這個元素幫人先看懂甚麼？這個效果是否遮住了訊息？這一版是否仍然像我們？

Jimmy 的結論是：風格可以變，閱讀次序、訊息層級和品牌邊界不能只靠生成器自己猜。

一張 visual brief 可先有五格：

| 格 | 需要寫清甚麼 |
|---|---|
| 第一眼 | 觀眾先要看到哪個字、物件或對比？ |
| 第二層 | 哪個說明支援主訊息，但不應搶走焦點？ |
| 留白與節奏 | 哪裡要讓內容呼吸，而不是繼續加元素？ |
| 品牌與事實 | 哪些 logo、產品細節、數字不能被 AI 自行改寫？ |
| Reference 用途 | 它只用來借閱讀方式、色調或節奏，還是可直接使用的 asset？ |

當 reviewer 說「太亂」時，就可以回到這五格判斷是第一眼不清、第二層太重，還是 reference 被錯誤理解。這比重複說「再高級啲」更能讓團隊累積能力。

## AI 產生多個版本時，點樣先不是抽盲盒？每一版只測一個創作判斷

AI 最大的誘惑是一次出二十個版本。數量本身不等於比較；如果每一版同時換了訊息、色調、構圖、字體和節奏，你最後只會選一個「感覺好啲」的，卻不知道真正起作用的是甚麼。下一次同類工作依然要由零試起。

把版本當成小型實驗，會讓創作快得更有方向。每輪只固定大部分條件，刻意測一個判斷，例如開場有沒有直接說出工作摩擦、第一頁標題是否清楚、或某個留白是否讓閱讀更順。人仍然是選擇和命名這個判斷的一方。

Jimmy 的結論是：版本愈多，不代表創作愈成熟；只有你知道每一版在測甚麼，才會留下可重用的品味。

先用這張版本比較卡：

| 欄位 | 本輪只寫一件事 |
|---|---|
| 固定條件 | 對象、核心訊息、已批准事實 |
| 變動項 | 只測開場、節奏、主視覺或 CTA 其中一項 |
| Review 問題 | 這項變動有否讓讀者更快理解？ |
| 選擇 | 保留哪一版，理由是甚麼？ |
| 下次 rule | 同類內容應先保留／避免甚麼？ |

這樣比較後，即使最後沒有一版可發，你也不會空手而回；你留下的是下一輪可以採用的 review rule。

## 用 AI 新手教學 carousel 跑一次：創作 workflow 怎樣保留人手品味

以下是 synthetic 例子。假設你要做一張給 AI 新手看的 carousel，核心不是推銷工具，而是讓讀者明白「你不是未識 prompt，而是未把一件真工作交代清楚」。材料只用公開教學觀點和自行撰寫的 dummy brief，不使用客戶畫面、私人數據或未公開品牌資產。

先由人定意圖和節奏，再讓 AI 協助生成不同構圖或文案草稿。最後的審核不是問「它是否有 AI 感」，而是問讀者能否看見工作摩擦、理解一個判斷，並知道可以安全試甚麼。

| 位置 | 本輪做法 | Review 位 |
|---|---|---|
| 創作意圖 | 新手看完知道第一件可交給 AI 的小工作 | 是否真有一個可採取動作 |
| 節奏線 | 痛點 → 常見誤會 → 五格工作交代 → 第一小步 | 有否在一頁塞完所有概念 |
| visual brief | 主標優先、輔助文字次之、留白讓人讀 | 第一眼是否看得出問題 |
| 版本比較 | 只測主標的問題式與陳述式兩種開場 | 哪一版最易讓對象認出自己 |
| release | owner 審核事實、品牌、可用性 | 不直接把 AI output 當完成 |

Jimmy 的結論是：AI 讓你更快看見可能性；品味則在你每次能否說清為何選這一版、又為何放棄另一版時慢慢累積。

這個流程不保證作品一定更受歡迎，但保證每次 review 不只是主觀投票，而是回到一套可對話、可改進的工作語言。

## 第一輪創作 workflow 應怎樣開始？先留一張 review card，不要急著做完整品牌系統

剛開始用 AI 做創作時，很多人會急著建立大量 prompt、收集大量 reference 或要求工具「記住我的風格」。這些可以日後再做；如果你還說不出每一版為何好或不好，更多素材只會放大選擇成本。

第一輪只選一個公開、低風險、可以由人手收回的內容。用一張 review card 將訊息、受眾、grammar、不可越過的邊界和最後選擇記下來。跑過幾次後，才判斷哪些規則真的穩定到值得寫成 template 或 Skill。

Jimmy 的結論是：創作 AI 的第一個成果不是一張最靚圖，而是一套讓你下次不用靠猜來 review 的語言。

review card 最少要留：

1. 對象和核心訊息；
2. 這輪只測的一個節奏或畫面判斷；
3. 已批准素材和不能變動的事實；
4. reviewer 選擇某版的理由；
5. 下一次可重用的一條規則。
