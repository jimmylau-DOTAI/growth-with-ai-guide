# AI Operator（AI工作操作者）：把重複工作變成可交接流程

一件工作明明你最熟，但同事、新 AI 或未來的自己仍然接不到；每次都要翻舊 chat、猜現況和重做決定。

重複工作不能只存在某個人的腦裡。先看清 trigger、input、owner、state、例外和 output，才知道應該寫 SOP、留 current-state note 還是停止。

> **完成這一關後，你會留下：** 一張 work map、minimum SOP、現況記錄和可交接的 context。

## 先由這篇開始

[工作明明你最熟，點解仍然交唔出去？先把工作從腦裡攤開](chapters/3-18-工作最熟仍交不出去，先把它攤開.md)

不用先讀完這一關所有文章。先用一篇最貼近現況的攻略做一次，再回來補你真正需要的部份。

## 暫時不用急著做

未需要把所有筆記變資料庫，也不要未跑穩便砌大型自動化。
