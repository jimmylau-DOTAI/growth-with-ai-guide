# AI Super User（AI熟練使用者）：讓 AI 讀懂你的工作

你已經可以叫 AI 幫手，但每次開新對話又要重講背景，初稿看似流暢，卻不夠貼近你的標準。

問題通常不在 prompt 長短，而在 AI 看不到目標、例子、證據、未知和你上次為何修改。這一關讓每次修正可以留下來，而不是下次重新猜。

> **完成這一關後，你會留下：** 一份任務包、可重用的 context、feedback rule 和 review 節奏。

## 先由這篇開始

[你唔係 Prompt 寫得唔夠長：AI 要見到你做事嘅 Context](chapters/2-13-start-here-context-and-feedback.md)

不用先讀完這一關所有文章。先用一篇最貼近現況的攻略做一次，再回來補你真正需要的部份。

## 暫時不用急著做

未需要把所有資料塞進去，也不用每星期換一個新工具。
